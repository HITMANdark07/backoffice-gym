# ShopGym M2: Ways In Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** make the M1 environment usable from outside, and record the first verified agent runs on free models. Agents reach it through an MCP server. RL code reaches it through an HTTP API and a Python client. mcp-evals runs and scores agents against it, and a replay tool turns recorded runs into step-by-step replays.

**Architecture:**
- **`@shopgym/mcp`** wraps `createEnv` in a low-level MCP `Server`, so the environment, not the SDK, validates arguments, and invalid arguments count as steps. It runs one episode per stdio session, with tools run straight from TypeScript through tsx, so there is no build step.
- **`@shopgym/api`** is a Hono app over the same `Env`, with an optional Postgres rate limiter.
- **`clients/python`** is a small httpx client.
- **mcp-evals** (a separate repo) gets three generic features:
  - per-task `vars` plus a `{suite_dir}` variable;
  - server `hidden_tools`;
  - an `env_reward` grader that calls a hidden scoring tool after the agent finishes.
- **`@shopgym/replay`** re-runs recorded tool calls on a fresh episode, using determinism to rebuild every step's store changes. It refuses to output a replay whose reward differs from the recorded one.

**Tech Stack:**
- Everything from M1 (TypeScript, Node 20, pnpm 10, Prisma 7.10.1, Postgres 17, zod 4.6.7, Vitest 2).
- MCP: `@modelcontextprotocol/sdk` 1.32.1.
- API: `hono` 4.13.13 with `@hono/node-server` 2.1.5.
- `tsx` 4.23.15.
- Python ≥ 3.10 with `httpx` and `pytest`, run through `uv`.
- mcp-evals at `~/Desktop/mcp-evals` (pnpm, tsup, Vitest).

**Spec:** `docs/superpowers/specs/2026-10-22-shopgym-design.md`. Read §6, §8 and §11. M2 is milestone 2 in §13. The M1 plan, `docs/superpowers/plans/2026-10-22-m1-environment-core.md`, shows the conventions already in place.

## Global Constraints

- **Toolchain:** Node ≥ 20.19, ESM only, pnpm 10.33.0. Pin exact versions: `@modelcontextprotocol/sdk` 1.32.1, `hono` 4.13.13, `@hono/node-server` 2.1.5, `tsx` 4.23.15.
- **Databases:** no Docker. Use only the local Homebrew Postgres databases `shopgym_dev` and `shopgym_test`. Tests use `shopgym_test`. The MCP server, API and replay default to `shopgym_dev`; override with `SHOPGYM_DATABASE_URL`.
- **Prisma:** schema changes go through `prisma migrate dev` in `packages/db`, then `pnpm generate` and `pnpm migrate:test`. CHECK constraints are appended to the migration by hand, as in M1.
- **Agents never see scores or expected values.**
  - `submit` returns only `{"submitted":true}`.
  - The scoring tool `__score` exists only for the harness. mcp-evals hides it, and the API never returns `expected`.
- **Infrastructure failures never count against an agent.**
  - In the MCP server, an `InfraError` makes the process exit with code 70, so the harness sees a crashed server and retries.
  - In the API, an `InfraError` returns 503 with a generic message.
- **Network binding:** the API binds to `127.0.0.1` when run locally, with no authentication. The rate limiter is only switched on by the cloud deployment (M5) and by tests.
- **mcp-evals changes:**
  - Made on a branch `feat/shopgym-support` in `~/Desktop/mcp-evals`, and kept generic: no ShopGym names in mcp-evals code.
  - Never push that branch or publish `mcp-arena`. Both are the owner's call.
- **Model runs:** use free OpenRouter models (`:free`) only. Every run uses a `--budget-usd` cap of at most 0.05. Any paid model needs the owner's explicit approval.
- **Secrets:** never read, print or create `.env` files. To check that the OpenRouter key exists, use `grep -c '^OPENROUTER_API_KEY=' .env`, which prints only a count.
- **Commits** end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Nothing is pushed.

### Decisions made while planning (refinements of the spec)

- **`hidden_tools` is a per-server option in mcp-evals**, not suite-wide, because tools belong to servers.
- **Per-task prompts and seeds:** mcp-evals gets per-task `vars` (substituted into server args and prompts) and a `{suite_dir}` variable. ShopGym generates the suite file, one task per template and seed, with each task's literal prompt. That's why the MCP server's `instructions` copy of the prompt is informational only.
- **Where outputs go:** M3's `apps/web` doesn't exist yet, so replays go to `evals/replays/` instead of `apps/web/content/runs/`. Recorded runs go to `evals/runs/<name>/`.
- **Rate-limit counters** live in a new `shopgym.rate_limits` table (fixed one-hour windows). It isn't tied to episodes.
- **The suite file lives in the shopgym repo** (`evals/shopgym.yaml`). It's run with the mcp-evals CLI built from its checkout: `node ~/Desktop/mcp-evals/packages/cli/dist/index.js`.

## Review Focus

These are inputs that real callers will send, which no task covers otherwise. Each line names the task whose tests pin it.

1. **The database fails during an MCP tool call.** The server should exit with code 70, so mcp-evals retries the run, instead of returning a tool error the model would see and be scored on. [Task 1, Task 2]
2. **API bodies that are not JSON, are a JSON array, or exceed 64 KB** should get a 400 or 413 with a JSON error, never a 500. [Task 3]
3. **One IP sending many `POST /episodes` requests** gets a 429 with a `retry-after` header, while other IPs are unaffected. [Task 4]
4. **A trace with tool calls that never reached the server** (invalid JSON, an unknown tool) **or calls made after `submit`** should replay without crashing, skipping the unanswered calls and keeping the post-submit errors. [Task 9]
5. **Prompts with quotes, newlines, `#`, `:` or non-ASCII text** should still produce a valid YAML suite, parsing back to exactly the same prompt. [Task 8]

```ts
import { Server } from '@modelcontextprotocol/sdk/server/index.js';
import { CallToolRequestSchema, ErrorCode, ListToolsRequestSchema, McpError } from '@modelcontextprotocol/sdk/types.js';
import { ENV_VERSION, getTool, InfraError, toolSchemas, type Env } from '@shopgym/core';

/** Harness-only tool returning the episode score. mcp-evals hides it from agents (server `hidden_tools`). */
export const SCORE_TOOL = '__score';

export interface ShopGymServerOptions {
  env: Env;
  task: string;
  seed: number;
  /** Called when the database fails. The stdio entry exits so the harness retries; it never becomes a tool result. */
  onInfraError?: (e: InfraError) => void;
}

export interface ShopGymServer {
  server: Server;
  episodeId: string;
  prompt: string;
}

const text = (t: string, isError = false) => ({ content: [{ type: 'text' as const, text: t }], ...(isError ? { isError: true } : {}) });

/**
 * One MCP session = one episode. The low-level Server is used on purpose: arguments go to the environment unvalidated,
 * so invalid arguments are the environment's tool errors and count as steps, exactly as over the RL API.
 */
export async function createShopGymServer(o: ShopGymServerOptions): Promise<ShopGymServer> {
  const reset = await o.env.reset({ task: o.task, seed: o.seed });
  const episodeId = reset.episode_id;
  const server = new Server({ name: 'shopgym', version: `env-${ENV_VERSION}` }, { capabilities: { tools: {} }, instructions: reset.task.prompt });
  const tools = [
    ...toolSchemas().map((t) => ({ name: t.name, description: t.description, inputSchema: t.input_schema as { type: 'object'; [k: string]: unknown } })),
    {
      name: SCORE_TOOL,
      description: 'Harness only: returns the episode score. Not part of the environment.',
      inputSchema: { type: 'object' as const, properties: {}, additionalProperties: false },
    },
  ];

  server.setRequestHandler(ListToolsRequestSchema, async () => ({ tools }));
  server.setRequestHandler(CallToolRequestSchema, async (req) => {
    const name = req.params.name;
    try {
      if (name === SCORE_TOOL) return text(JSON.stringify(await o.env.score(episodeId)));
      const r = await o.env.step(episodeId, { tool: name, args: req.params.arguments ?? {} });
      if (!r.ok) return text(r.error ?? 'error', true);
      const capped = r.done && getTool(name)?.kind !== 'end';
      return text(JSON.stringify(r.result) + (capped ? '\nThe step limit was reached; the episode is over.' : ''));
    } catch (e) {
      if (e instanceof InfraError) {
        o.onInfraError?.(e);
        throw new McpError(ErrorCode.InternalError, `environment unavailable: ${e.message}`);
      }
      throw e;
    }
  });

  return { server, episodeId, prompt: reset.task.prompt };
}
```

```ts
export interface CliArgs {
  task: string;
  seed: number;
  databaseUrl?: string;
}

export class UsageError extends Error {
  override name = 'UsageError';
}

export const USAGE = 'usage: shopgym-mcp --task <slug> --seed <int> [--database-url <url>]';

export function parseArgs(argv: string[]): CliArgs {
  const out: Partial<CliArgs> = {};
  for (let i = 0; i < argv.length; i += 2) {
    const flag = argv[i];
    const value = argv[i + 1];
    if (flag !== '--task' && flag !== '--seed' && flag !== '--database-url') throw new UsageError(`unknown argument ${flag}`);
    if (value === undefined || value.startsWith('--')) throw new UsageError(`${flag} needs a value`);
    if (flag === '--task') out.task = value;
    else if (flag === '--seed') {
      if (!/^\d+$/.test(value)) throw new UsageError('--seed must be a non-negative integer');
      out.seed = Number(value);
    } else out.databaseUrl = value;
  }
  if (out.task === undefined || out.seed === undefined) throw new UsageError('--task and --seed are required');
  return out as CliArgs;
}
```

```ts
import { StdioServerTransport } from '@modelcontextprotocol/sdk/server/stdio.js';
import { createEnv } from '@shopgym/core';
import { createDb, devDatabaseUrl } from '@shopgym/db';
import { parseArgs, USAGE, UsageError, type CliArgs } from './args';
import { createShopGymServer } from './server';

const fail = (message: string, code: number): never => {
  process.stderr.write(`shopgym-mcp: ${message}\n`);
  process.exit(code);
};

/** Entry for bin/shopgym-mcp.mjs. Never writes to stdout: stdout is the MCP channel. */
export async function run(argv: string[]): Promise<void> {
  let args: CliArgs;
  try {
    args = parseArgs(argv);
  } catch (e) {
    return fail(e instanceof UsageError ? `${e.message}\n${USAGE}` : String(e), 64);
  }
  const db = createDb(args.databaseUrl ?? devDatabaseUrl());
  try {
    const { server } = await createShopGymServer({
      env: createEnv(db),
      task: args.task,
      seed: args.seed,
      // Exiting closes the connection: mcp-evals sees a crashed server (retryable), never a tool error.
      onInfraError: (e) => fail(e.message, 70),
    });
    server.onclose = () => {
      void db.$disconnect();
    };
    await server.connect(new StdioServerTransport());
  } catch (e) {
    await db.$disconnect().catch(() => {});
    fail(e instanceof Error ? e.message : String(e), 1);
  }
}
```

- Produces: `createApi(o)`, `interface RateLimiter`, `interface ApiOptions`.
- **Routes**, all under `/api`:
  - `GET /tasks`
  - `POST /episodes` (returns 201)
  - `POST /episodes/:id/step`
  - `POST /episodes/:id/score`
  - `GET /episodes/:id`
  - `GET /health`
- **Status codes:**
  - 400 for bad input, an unknown task or a bad seed;
  - 404 for an unknown episode or route;

```ts
import { randomInt } from 'node:crypto';
import { EnvError, GENERIC_CHECKS, InfraError, MAX_SEED, TASKS, type Env } from '@shopgym/core';
import { Hono, type Context } from 'hono';
import { bodyLimit } from 'hono/body-limit';

export type LimitBucket = 'episodes' | 'steps';

export interface RateLimiter {
  hit(key: string, bucket: LimitBucket): Promise<{ ok: boolean; retryAfterS: number }>;
}

export interface ApiOptions {
  env: Env;
  /** Owner recorded on new episodes; 'anon' episodes expire after an hour. */
  owner?: string;
  /** Off locally; the cloud deployment turns it on. */
  limiter?: RateLimiter;
  /** The client's address for rate limiting. */
  clientIp?: (c: Context) => string;
  /** Extra cleanup for GET /api/health. */
  onHealth?: () => Promise<void>;
}

class HttpError extends Error {
  constructor(
    readonly status: 400 | 404 | 413 | 429,
    message: string,
    readonly retryAfterS?: number,
  ) {
    super(message);
  }
}

async function readJson(c: Context): Promise<Record<string, unknown>> {
  const raw = await c.req.text();
  if (raw.trim() === '') return {};
  let parsed: unknown;
  try {
    parsed = JSON.parse(raw);
  } catch {
    throw new HttpError(400, 'the body must be JSON');
  }
  if (typeof parsed !== 'object' || parsed === null || Array.isArray(parsed)) throw new HttpError(400, 'the body must be a JSON object');
  return parsed as Record<string, unknown>;
}

export function createApi(o: ApiOptions): Hono {
  const app = new Hono().basePath('/api');
  const owner = o.owner ?? 'anon';
  const ipOf = o.clientIp ?? (() => 'local');

  const limit = async (c: Context, bucket: LimitBucket) => {
    if (!o.limiter) return;
    const r = await o.limiter.hit(ipOf(c), bucket);
    if (!r.ok) throw new HttpError(429, `too many ${bucket}; try again later`, r.retryAfterS);
  };

  app.use('*', bodyLimit({ maxSize: 64 * 1024, onError: (c) => c.json({ error: 'the body is larger than 64 KB' }, 413) }));

  app.onError((e, c) => {
    if (e instanceof HttpError) {
      if (e.retryAfterS !== undefined) c.header('retry-after', String(e.retryAfterS));
      return c.json({ error: e.message }, e.status);
    }
    if (e instanceof EnvError) return c.json({ error: e.message, code: e.code }, e.code === 'not_found' ? 404 : 400);
    if (e instanceof InfraError) return c.json({ error: 'the environment is temporarily unavailable' }, 503);
    return c.json({ error: 'internal error' }, 500);
  });

  app.get('/tasks', (c) =>
    c.json({
      tasks: TASKS.map((t) => ({
        slug: t.slug,
        title: t.title,
        summary: t.summary,
        checks: [
          ...t.checks.map((ch) => ({ id: ch.id, kind: ch.kind, weight: ch.kind === 'required' ? (ch.weight ?? 1) : 0, description: ch.description })),
          ...GENERIC_CHECKS.map((g) => ({ id: g.id, kind: g.kind, weight: 0, description: g.description })),
        ],
      })),
    }),
  );

  app.post('/episodes', async (c) => {
    const body = await readJson(c);
    if (typeof body.task !== 'string') throw new HttpError(400, 'task is required');
    if (body.seed !== undefined && typeof body.seed !== 'number') throw new HttpError(400, 'seed must be an integer');
    await limit(c, 'episodes');
    const seed = typeof body.seed === 'number' ? body.seed : randomInt(0, MAX_SEED);
    return c.json(await o.env.reset({ task: body.task, seed, owner }), 201);
  });

  app.post('/episodes/:id/step', async (c) => {
    const body = await readJson(c);
    if (typeof body.tool !== 'string') throw new HttpError(400, 'tool is required');
    await limit(c, 'steps');
    return c.json(await o.env.step(c.req.param('id'), { tool: body.tool, args: body.args }));
  });

  app.post('/episodes/:id/score', async (c) => c.json(await o.env.score(c.req.param('id'))));
  app.get('/episodes/:id', async (c) => c.json(await o.env.getEpisode(c.req.param('id'))));

  app.get('/health', async (c) => {
    const expired = await o.env.expireEpisodes(100);
    await o.onHealth?.();
    return c.json({ ok: true, expired_episodes: expired });
  });

  app.notFound((c) => c.json({ error: 'not found' }, 404));
  return app;
}
```

```ts
import { InfraError } from '@shopgym/core';
import type { ShopDb } from '@shopgym/db';
import type { LimitBucket, RateLimiter } from './app';

export interface LimitRule {
  max: number;
  windowMs: number;
}

/** Spec §6: 30 episodes and 600 steps per IP per hour. */
export const DEFAULT_LIMITS: Record<LimitBucket, LimitRule> = {
  episodes: { max: 30, windowMs: 3_600_000 },
  steps: { max: 600, windowMs: 3_600_000 },
};

/** Fixed-window counters in shopgym.rate_limits, one upsert per hit. */
export function createPgRateLimiter(
  db: ShopDb,
  limits: Record<LimitBucket, LimitRule> = DEFAULT_LIMITS,
  now: () => Date = () => new Date(),
): RateLimiter & { prune(olderThanMs?: number): Promise<number> } {
  return {
    async hit(key, bucket) {
      const rule = limits[bucket];
      const t = now().getTime();
      const start = new Date(Math.floor(t / rule.windowMs) * rule.windowMs);
      try {
        const rows = await db.$queryRawUnsafe<Array<{ count: number }>>(
          `INSERT INTO "shopgym"."rate_limits" (key, bucket, window_start, count) VALUES ($1, $2, $3, 1)
           ON CONFLICT (key, bucket, window_start) DO UPDATE SET count = "rate_limits".count + 1
           RETURNING count`,
          key,
          bucket,
          start,
        );
        const count = Number(rows[0]?.count ?? 0);
        return { ok: count <= rule.max, retryAfterS: Math.ceil((start.getTime() + rule.windowMs - t) / 1000) };
      } catch (e) {
        throw new InfraError(`rate limiter: ${e instanceof Error ? e.message : String(e)}`, { cause: e });
      }
    },
    async prune(olderThanMs = 86_400_000) {
      return db.$executeRawUnsafe('DELETE FROM "shopgym"."rate_limits" WHERE window_start < $1', new Date(now().getTime() - olderThanMs));
    },
  };
}
```

```python
"""HTTP client for the ShopGym RL API (spec §6)."""
from __future__ import annotations

from typing import Any

import httpx


class ShopGymError(Exception):
    """The API answered with an error status."""

    def __init__(self, status: int, message: str, code: str | None = None) -> None:
        super().__init__(f"{status}: {message}")
        self.status = status
        self.message = message
        self.code = code


class ShopGym:
    """Gymnasium-style client: reset() a task, step() tools, score() the episode."""

    def __init__(self, base_url: str = "http://127.0.0.1:8787", *, timeout: float = 30.0, client: httpx.Client | None = None) -> None:
        self._http = client or httpx.Client(base_url=base_url.rstrip("/") + "/api", timeout=timeout)
        self.episode_id: str | None = None
        self.done = False

    def __enter__(self) -> ShopGym:
        return self

    def __exit__(self, *exc: object) -> None:
        self.close()

    def close(self) -> None:
        self._http.close()

    def tasks(self) -> list[dict[str, Any]]:
        return self._request("GET", "/tasks")["tasks"]

    def reset(self, task: str, seed: int | None = None) -> dict[str, Any]:
        payload: dict[str, Any] = {"task": task}
        if seed is not None:
            payload["seed"] = seed
        obs = self._request("POST", "/episodes", payload)
        self.episode_id = obs["episode_id"]
        self.done = False
        return obs

    def step(self, tool: str, args: dict[str, Any] | None = None) -> tuple[dict[str, Any], bool]:
        result = self._request("POST", f"/episodes/{self._require_episode()}/step", {"tool": tool, "args": args or {}})
        self.done = bool(result["done"])
        return result, self.done

    def score(self) -> dict[str, Any]:
        return self._request("POST", f"/episodes/{self._require_episode()}/score", {})

    def episode(self) -> dict[str, Any]:
        return self._request("GET", f"/episodes/{self._require_episode()}")

    def _require_episode(self) -> str:
        if self.episode_id is None:
            raise RuntimeError("call reset() first")
        return self.episode_id

    def _request(self, method: str, path: str, json: dict[str, Any] | None = None) -> dict[str, Any]:
        response = self._http.request(method, path, json=json)
        try:
            body = response.json()
        except ValueError:
            body = {"error": response.text}
        if response.status_code >= 400:
            raise ShopGymError(response.status_code, str(body.get("error", "request failed")), body.get("code"))
        return body
```

```ts
import { TASKS } from '@shopgym/core';

export interface SuiteModel {
  id: string;
  /** OpenRouter provider pin; omit for mock models. */
  provider?: string;
}

/** Free OpenRouter models that completed a full mcp-evals run before (2026-10-21). */
export const FREE_MODELS: SuiteModel[] = [
  { id: 'minimax/minimax-m3.1-flash:free', provider: 'minimax' },
  { id: 'nvidia/nemotron-3-ultra-550b-a55b:free', provider: 'nvidia' },
];

export const taskId = (slug: string, seed: number): string => `${slug}--s${seed}`;

/** JSON strings are valid YAML double-quoted scalars, so this quotes anything safely. */
const q = (s: string): string => JSON.stringify(s);

export interface BuildSuiteOptions {
  models: SuiteModel[];
  seeds: number[];
  slugs?: string[];
  name?: string;
  /** Path of the bin from the suite file's directory. */
  serverPath?: string;
  /** Test hook: replace every prompt. */
  promptOverride?: string;
}

/** An mcp-evals suite: one task per template × seed, scored by the hidden __score tool. */
export function buildSuiteYaml(o: BuildSuiteOptions): string {
  const tasks = TASKS.filter((t) => !o.slugs || o.slugs.includes(t.slug));
  const serverPath = o.serverPath ?? '{suite_dir}/../packages/mcp/bin/shopgym-mcp.mjs';
  const lines = [
    '# Generated by packages/mcp/scripts/write-suite.ts. Do not edit by hand.',
    `suite: ${o.name ?? 'shopgym'}`,
    'version: 1',
    'servers:',
    '  shopgym:',
    '    command: node',
    `    args: [${[serverPath, '--task', '{task}', '--seed', '{seed}'].map(q).join(', ')}]`,
    '    hidden_tools: [__score]',
    'models:',
    ...o.models.map((m) => (m.provider ? `  - { id: ${q(m.id)}, provider: ${q(m.provider)} }` : `  - ${q(m.id)}`)),
    'defaults: { repeats: 1, max_steps: 40, timeout_s: 300, temperature: 0 }',
    'tasks:',
  ];
  for (const t of tasks) {
    for (const seed of o.seeds) {
      lines.push(
        `  - id: ${taskId(t.slug, seed)}`,
        `    prompt: ${q(o.promptOverride ?? t.generate(seed).prompt)}`,
        `    vars: { task: ${q(t.slug)}, seed: ${q(String(seed))} }`,
        '    graders: [{ type: env_reward, tool: __score, min: 1 }]',
      );
    }
  }
  return `${lines.join('\n')}\n`;
}
```

```ts
import { ENV_VERSION, type Env, type ScoreResult } from '@shopgym/core';
import { diffDumps, dumpEpisode, type DiffEntry, type ShopDb } from '@shopgym/db';

/** The subset of an mcp-evals trace line that replays need. */
export interface TraceLike {
  runKey: string;
  suite: string;
  server: string;
  model: string;
  task: string;
  outcome: string;
  graders: Array<{ type: string; value?: number }>;
  events: Array<{ type: string; callId?: string; tool?: string; args?: Record<string, unknown> | null }>;
}

export interface ReplayStep {
  n: number;
  tool: string;
  args: unknown;
  ok: boolean;
  result?: unknown;
  error?: string;
  /** Store rows this step added, removed or changed. */
  changes: DiffEntry[];
}

export interface Replay {
  version: 1;
  env_version: number;
  run: { run_key: string; model: string; task: string; seed: number; outcome: string; recorded_reward: number | null };
  prompt: string;
  store_date: string;
  steps: ReplayStep[];
  score: ScoreResult;
}

export class ReplayMismatchError extends Error {
  override name = 'ReplayMismatchError';
}

export function parseTaskId(id: string): { task: string; seed: number } {
  const m = /^([a-z0-9-]+?)--s(\d+)$/.exec(id);
  if (!m) throw new Error(`task id "${id}" is not <slug>--s<seed>`);
  return { task: m[1] as string, seed: Number(m[2]) };
}

/** Tool calls that reached the server: those with a tool_result. Unknown tools and invalid JSON never did. */
export function replayableCalls(trace: TraceLike): Array<{ tool: string; args: unknown }> {
  const answered = new Set(trace.events.filter((e) => e.type === 'tool_result').map((e) => e.callId));
  return trace.events
    .filter((e) => e.type === 'tool_call' && answered.has(e.callId))
    .map((e) => ({ tool: e.tool as string, args: e.args ?? {} }));
}

/** Re-runs a recorded run on a fresh episode with the same task and seed. Determinism makes the result identical. */
export async function replayTrace(env: Env, db: ShopDb, trace: TraceLike): Promise<Replay> {
  const { task, seed } = parseTaskId(trace.task);
  const reset = await env.reset({ task, seed, owner: 'system' });
  const id = reset.episode_id;
  const steps: ReplayStep[] = [];
  let before = await dumpEpisode(db, id);
  for (const call of replayableCalls(trace)) {
    const r = await env.step(id, { tool: call.tool, args: call.args });
    const after = await dumpEpisode(db, id);
    steps.push({ n: r.step, tool: call.tool, args: call.args, ok: r.ok, ...(r.ok ? { result: r.result } : { error: r.error }), changes: diffDumps(before, after) });
    before = after;
  }
  const score = await env.score(id);
  const recorded = trace.graders.find((g) => g.type === 'env_reward')?.value ?? null;
  if (recorded !== null && recorded !== score.reward) {
    throw new ReplayMismatchError(`${trace.runKey}: replayed reward ${score.reward} differs from recorded ${recorded}`);
  }
  return {
    version: 1,
    env_version: ENV_VERSION,
    run: { run_key: trace.runKey, model: trace.model, task, seed, outcome: trace.outcome, recorded_reward: recorded },
    prompt: reset.task.prompt,
    store_date: reset.store_date,
    steps,
    score,
  };
}
```

```ts
/** Reads an mcp-evals traces.jsonl (or .jsonl.gz). */
export async function readTraces(path: string): Promise<TraceLike[]> {
```

```ts
import { join, resolve } from 'node:path';
import { createEnv } from '@shopgym/core';
import { createDb, devDatabaseUrl } from '@shopgym/db';
import { replayTrace, ReplayMismatchError } from './replay';
import { readTraces } from './traces';

function arg(name: string): string {
  const i = process.argv.indexOf(name);
  const v = i === -1 ? undefined : process.argv[i + 1];
  if (!v) {
    console.error('usage: pnpm replay --traces <traces.jsonl[.gz]> --out <dir>');
    process.exit(64);
  }
  return v;
}

const tracesPath = resolve(process.env.INIT_CWD ?? process.cwd(), arg('--traces'));
const outDir = resolve(process.env.INIT_CWD ?? process.cwd(), arg('--out'));
const db = createDb(devDatabaseUrl());
const env = createEnv(db);
const safe = (s: string) => s.replace(/[^a-zA-Z0-9._-]+/g, '_');

mkdirSync(outDir, { recursive: true });
const index: Array<{ file: string; model: string; task: string; seed: number; reward: number; recorded: number | null }> = [];
let mismatches = 0;
try {
  for (const trace of await readTraces(tracesPath)) {
    if (trace.outcome === 'error') continue;
    try {
      const replay = await replayTrace(env, db, trace);
      const file = `${safe(trace.runKey)}.json`;
      writeFileSync(join(outDir, file), `${JSON.stringify(replay, null, 2)}\n`);
      index.push({ file, model: replay.run.model, task: replay.run.task, seed: replay.run.seed, reward: replay.score.reward, recorded: replay.run.recorded_reward });

} finally {
  await db.$disconnect();
}
```
