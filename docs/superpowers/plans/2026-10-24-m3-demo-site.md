# BackOffice Gym M3: Demo Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a Next.js 16 demo site, server-rendered for search engines, that shows BackOffice Gym through its 48 real recorded runs:
- a landing page with an auto-playing split-screen replay;
- a page per task and a page per run, with a scrubber;
- a "Try it yourself" console that drives a live episode through the API;
- an About page;
- Open Graph images, a sitemap and robots.

**Architecture:**
- **`apps/web`** is a Next.js 16.2.4 App Router app inside the pnpm workspace.
- **Pages render at build time** from the replay JSON in `evals/replays/free-2026-10/` (`generateStaticParams`, `dynamicParams = false`).
- **Replays become self-contained.** Version 2 adds the starting store snapshot, step numbers by position, and the score "if the agent stopped here" after every step. The player can then rebuild the store at any step in the browser, with no database.
- **The live API** is the existing Hono app, mounted at `/api/[...route]`. The workspace packages are compiled by Next (`transpilePackages`), and Prisma stays external (`serverExternalPackages`). A throwaway test on 2026-10-24 confirmed this builds and serves `/api` with Prisma 7.
- **The look** is the portfolio's: tokens, fonts and the approved run-page mockup.

**Tech Stack:**
- Next.js 16.2.4, React 19.2.4, Tailwind CSS 4.3.3 (`@tailwindcss/postcss` 4.3.3), `@types/react` / `@types/react-dom` 19.3.0.
- Fonts from `next/font/google` (Geist, Instrument Serif, JetBrains Mono).
- Open Graph images with `next/og` `ImageResponse`.
- Vitest 2 for tests: node environment, `react-dom/server`, `renderToString`.
- Playwright MCP for the final manual walkthrough.

**Spec:** `docs/superpowers/specs/2026-10-22-backoffice-gym-design.md`, §9 (pages and look) and §11 (web testing). The approved run-page mockup is described in Task 6. M3 covers only the M3 pages in §13. `/runs/new`, `/settings/keys`, `/terms` and `/privacy` are M4.

## Global Constraints

- **Pinned versions:** `next` 16.2.4, `react` and `react-dom` 19.2.4, `tailwindcss` and `@tailwindcss/postcss` 4.3.3, `@types/react` and `@types/react-dom` 19.3.0. No other UI or animation libraries: CSS transitions only.
- **No Docker; local Postgres only.** Every page except `/try/*` and `/api/*` must render without a database. `/api` uses `BACKOFFICE_GYM_DATABASE_URL`, defaulting to `backoffice_gym_dev`.
- **Honesty:** every number on the site comes from `evals/replays/free-2026-10/` or `TASKS`. Featured-run captions only claim what a test checks against the replay: its reward, and that the named tool call exists.
- **Agents' hidden data never reaches the browser:**
  - no `expected` values;
  - check details shown are those recorded in the replay's `score` and `score_after`;
  - task pages show check descriptions only.
- **Look:**
  - the portfolio tokens, light by default and dark through `prefers-color-scheme` (values in Task 2);
  - Instrument Serif for headings, Geist for text, JetBrains Mono for tool calls;
  - cobalt accent `#1d4ed8` (`#8ab4ff` in dark mode).
- **Accessibility:**
  - everything works by keyboard: Space and ← → in the player;
  - visible focus rings;
  - `prefers-reduced-motion` turns autoplay off;
  - no horizontal page scroll at 390 px width.
- **SEO:** every page has a `<title>`, a meta description and an `og:image` (Task 11 checks this).
- **Run IDs** match `/^[a-z0-9]+$/i`. Anything else is a 404.
- **Secrets:** never read, print or create `.env` files.
- **Commits** end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Nothing is pushed without the owner's go-ahead.

### Decisions made while planning (refinements of the spec)

- **No Framer Motion.** CSS transitions plus a persistent highlight on the step being shown are enough. A highlight that stays visible is clearer when paused and under reduced motion. The spec mentioned Framer Motion.
- **Replay format version 2:**
  - `initial` (the store at reset);
  - `steps[].n` numbered by position, plus `env_step`, which fixes the M2 "repeated step numbers after submit" minor;
  - `steps[].score_after`, computed with the real scorer on the store after that step, using the task's expected outcome regenerated from the seed.
  - The 48 replays are regenerated, and must still match their recorded rewards.
- **"Try it yourself" is a tool console:** forms generated from each tool's JSON Schema, a log of results and the final score. It is not a full click-through store UI, which isn't needed to prove the scoring is real.
- **No rate limiter or IP handling in M3.** It runs locally; the M5 deployment switches the limiter on.
- **Run pages first render the final step** (final store and full scorecard), so the HTML search engines see is informative. `?step=n` deep links seek after hydration.

```ts
import { ENV_VERSION, getTask, scoreTask, type Env, type ScoreResult } from '@backoffice-gym/core';
import { diffDumps, dumpEpisode, type DiffEntry, type Dump, type ShopDb } from '@backoffice-gym/db';

/** The subset of an mcp-evals trace line that replays need. */
export interface TraceLike {
  runKey: string;
  suite: string;
  server: string;
  model: string;
  task: string;
  outcome: string;
  graders: Array<{ type: string; value?: number }>;
  events: Array<{ type: string; callId?: string; tool?: string; args?: Record<string, unknown> | null }>;
}

export interface ReplayStep {
  /** Position in the replay, 1-based. */
  n: number;
  /** The environment's step number (repeats after the episode ends). */
  env_step: number;
  tool: string;
  args: unknown;
  ok: boolean;
  result?: unknown;
  error?: string;
  /** Store rows this step added, removed or changed. */
  changes: DiffEntry[];
  /** The score if the agent had stopped right after this step. */
  score_after: ScoreResult;
}

export interface Replay {
  version: 2;
  env_version: number;
  run: { run_key: string; model: string; task: string; seed: number; outcome: string; recorded_reward: number | null };
  prompt: string;
  store_date: string;
  /** The store right after reset, before any step. */
  initial: Dump;
  steps: ReplayStep[];
  score: ScoreResult;
}

export class ReplayMismatchError extends Error {
  override name = 'ReplayMismatchError';
}

export function parseTaskId(id: string): { task: string; seed: number } {
  const m = /^([a-z0-9-]+?)--s(\d+)$/.exec(id);
  if (!m) throw new Error(`task id "${id}" is not <slug>--s<seed>`);
  return { task: m[1] as string, seed: Number(m[2]) };
}

/** Tool calls that reached the server: those with a tool_result. Unknown tools and invalid JSON never did. */
export function replayableCalls(trace: TraceLike): Array<{ tool: string; args: unknown }> {
  const answered = new Set(trace.events.filter((e) => e.type === 'tool_result').map((e) => e.callId));
  return trace.events
    .filter((e) => e.type === 'tool_call' && answered.has(e.callId))
    .map((e) => ({ tool: e.tool as string, args: e.args ?? {} }));
}

/** Re-runs a recorded run on a fresh episode with the same task and seed. Determinism makes the result identical. */
export async function replayTrace(env: Env, db: ShopDb, trace: TraceLike): Promise<Replay> {
  const { task, seed } = parseTaskId(trace.task);
  const template = getTask(task);
  if (!template) throw new Error(`unknown task "${task}"`);
  const expected = template.generate(seed).expected;
  const reset = await env.reset({ task, seed, owner: 'system' });
  const id = reset.episode_id;
  const initial = await dumpEpisode(db, id);
  const steps: ReplayStep[] = [];
  let before = initial;
  const calls = replayableCalls(trace);
  for (let i = 0; i < calls.length; i++) {
    const call = calls[i]!;
    const r = await env.step(id, { tool: call.tool, args: call.args });
    const after = await dumpEpisode(db, id);
    const scoreAfter = scoreTask(template, { expected, initial, final: after, diff: diffDumps(initial, after), storeDate: reset.store_date });
    steps.push({
      n: i + 1,
      env_step: r.step,
      tool: call.tool,
      args: call.args,
      ok: r.ok,
      ...(r.ok ? { result: r.result } : { error: r.error }),
      changes: diffDumps(before, after),
      score_after: scoreAfter,
    });
    before = after;
  }
  const score = await env.score(id);
  const recorded = trace.graders.find((g) => g.type === 'env_reward')?.value ?? null;
  if (recorded !== null && recorded !== score.reward) {
    throw new ReplayMismatchError(`${trace.runKey}: replayed reward ${score.reward} differs from recorded ${recorded}`);
  }
  return {
    version: 2,
    env_version: ENV_VERSION,
    run: { run_key: trace.runKey, model: trace.model, task, seed, outcome: trace.outcome, recorded_reward: recorded },
    prompt: reset.task.prompt,
    store_date: reset.store_date,
    initial,
    steps,
    score,
  };
}
```

```ts
import { existsSync, readFileSync } from 'node:fs';
import { join } from 'node:path';
import { TASKS } from '@backoffice-gym/core';
import type { Replay } from '@backoffice-gym/replay';

/** The recorded run set the site shows. */
export const RUN_SET = 'free-2026-10';

/** Repo root: the cwd when tests run from the root, two levels up when Next runs in apps/web. */
const repoRoot = (): string => (existsSync(join(process.cwd(), 'evals')) ? process.cwd() : join(process.cwd(), '..', '..'));
const replaysDir = (): string => join(repoRoot(), 'evals', 'replays', RUN_SET);

export interface RunSummary {
  id: string;
  model: string;
  task: string;
  seed: number;
  reward: number;
  steps: number;
}

let runsCache: RunSummary[] | null = null;

export function listRuns(): RunSummary[] {
  if (runsCache) return runsCache;
  const raw = JSON.parse(readFileSync(join(replaysDir(), 'index.json'), 'utf8')) as RunSummary[];
  const order = (slug: string) => TASKS.findIndex((t) => t.slug === slug);
  runsCache = raw
    .map(({ id, model, task, seed, reward, steps }) => ({ id, model, task, seed, reward, steps }))
    .sort((a, b) => order(a.task) - order(b.task) || a.model.localeCompare(b.model) || a.seed - b.seed);
  return runsCache;
}

/** A recorded run's replay. Only plain ids listed in the index are read. */
export function getReplay(id: string): Replay | null {
  if (!/^[a-z0-9]+$/i.test(id) || !listRuns().some((r) => r.id === id)) return null;
  const file = join(replaysDir(), `${id}.json`);
  return existsSync(file) ? (JSON.parse(readFileSync(file, 'utf8')) as Replay) : null;
}

export const runsForTask = (slug: string): RunSummary[] => listRuns().filter((r) => r.task === slug);
export const models = (): string[] => [...new Set(listRuns().map((r) => r.model))].sort();
export const taskTitle = (slug: string): string => TASKS.find((t) => t.slug === slug)?.title ?? slug;

export interface HeatCell {
  model: string;
  task: string;
  passed: number;
  total: number;
}

export function heatmap(): HeatCell[] {
  const runs = listRuns();
  return models().flatMap((model) =>
    TASKS.map((t) => {
      const mine = runs.filter((r) => r.model === model && r.task === t.slug);
      return { model, task: t.slug, passed: mine.filter((r) => r.reward === 1).length, total: mine.length };
    }),
  );
}

export function stats() {
  const runs = listRuns();
  return {
    runs: runs.length,
    models: models().length,
    tasks: TASKS.length,
    traps: TASKS.filter((t) => t.slug.endsWith('-trap')).length,
    perfect: runs.filter((r) => r.reward === 1).length,
  };
}
```

```ts
import type { ScoreResult } from '@backoffice-gym/core';
import type { DiffEntry, Dump, Row, TableName } from '@backoffice-gym/db';
import type { Replay } from '@backoffice-gym/replay';

/** Row ids a step changed, per table. */
export type Changed = Partial<Record<TableName, Set<number>>>;

type Steps = Pick<Replay, 'initial' | 'steps'>;

const clampStep = (r: Steps, step: number): number => Math.max(0, Math.min(Math.trunc(step), r.steps.length));

function apply(state: Dump, c: DiffEntry): void {
  const rest = (state[c.table] ?? []).filter((row) => Number(row.id) !== c.id);
  state[c.table] = c.op === 'remove' ? rest : [...rest, c.after as Row].sort((a, b) => Number(a.id) - Number(b.id));
}

/** The store after `step` steps (0 = the store at reset). */
export function stateAt(replay: Steps, step: number): Dump {
  const state = structuredClone(replay.initial) as Dump;
  const upto = clampStep(replay, step);
  for (let i = 0; i < upto; i++) for (const c of replay.steps[i]!.changes) apply(state, c);
  return state;
}

export function changedAt(replay: Steps, step: number): Changed {
  if (step < 1 || step > replay.steps.length) return {};
  const out: Changed = {};
  for (const c of replay.steps[step - 1]!.changes) (out[c.table] ??= new Set<number>()).add(c.id);
  return out;
}

export function scoreAt(replay: Pick<Replay, 'steps'>, step: number): ScoreResult | null {
  if (step < 1 || replay.steps.length === 0) return null;
  return replay.steps[Math.min(step, replay.steps.length) - 1]!.score_after;
}

/** The first step after which a forbidden check fails (reward 0 from then on), or null. */
export function firstFailingStep(replay: Pick<Replay, 'steps'>): number | null {
  const i = replay.steps.findIndex((s) => s.score_after.checks.some((c) => c.kind === 'forbidden' && !c.passed));
  return i === -1 ? null : i + 1;
}
```

```ts
export interface PlayerState {
  step: number;
  total: number;
  playing: boolean;
  ended: boolean;
}

export type PlayerAction =
  | { type: 'play' }
  | { type: 'pause' }
  | { type: 'toggle' }
  | { type: 'next' }
  | { type: 'prev' }
  | { type: 'seek'; step: number }
  | { type: 'tick' };

const clamp = (n: number, total: number): number => Math.max(0, Math.min(Math.trunc(n), total));

export const initialPlayer = (total: number, step: number): PlayerState => ({ step: clamp(step, total), total, playing: false, ended: false });

export function playerReducer(s: PlayerState, a: PlayerAction): PlayerState {
  switch (a.type) {
    case 'play':
      return { ...s, playing: s.total > 0, ended: false, step: s.step >= s.total ? 0 : s.step };
    case 'pause':
      return { ...s, playing: false };
    case 'toggle':
      return playerReducer(s, { type: s.playing ? 'pause' : 'play' });
    case 'next':
      return { ...s, playing: false, step: clamp(s.step + 1, s.total) };
    case 'prev':
      return { ...s, playing: false, step: clamp(s.step - 1, s.total) };
    case 'seek':
      return { ...s, playing: false, step: clamp(a.step, s.total) };
    case 'tick': {
      if (!s.playing) return s;
      const step = clamp(s.step + 1, s.total);
      return step >= s.total ? { ...s, step, playing: false, ended: true } : { ...s, step };
    }
  }
}

/** The `step` query value if it is a whole number within 0..total; otherwise null. */
export function parseStepParam(search: string, total: number): number | null {
  const raw = new URLSearchParams(search).get('step');
  if (raw === null || !/^\d+$/.test(raw)) return null;
  const n = Number(raw);
  return n <= total ? n : null;
}

export const shouldAutoplay = (autoplay: boolean, reducedMotion: boolean): boolean => autoplay && !reducedMotion;
```

```tsx
import type { CheckResult, ScoreResult } from '@backoffice-gym/core';
import type { Replay } from '@backoffice-gym/replay';
import { checkLabel, rewardLabel } from '@/lib/format';

type Status = 'ok' | 'bad' | 'wait';

function status(c: CheckResult, step: number, done: boolean): Status {
  if (step === 0) return 'wait';
  if (c.kind === 'forbidden') return c.passed ? 'ok' : 'bad';
  return c.passed ? 'ok' : done ? 'bad' : 'wait';
}

const ICON: Record<Status, { glyph: string; label: string; cls: string }> = {
  ok: { glyph: '✓', label: 'passed', cls: 'bg-ok-bg text-ok' },
  bad: { glyph: '✕', label: 'failed', cls: 'bg-bad-bg text-bad' },
  wait: { glyph: '', label: 'pending', cls: 'border border-dashed border-border' },
};

export function Scorecard({ replay, step, score }: { replay: Replay; step: number; score: ScoreResult | null }) {
  const done = step >= replay.steps.length;
  const checks = (score ?? replay.score).checks;
  const headline =
```

```tsx
'use client';

import type { Replay } from '@backoffice-gym/replay';
import { useEffect, useMemo, useReducer } from 'react';
import { StorePanel } from '@/components/store/store-panel';
import { initialPlayer, parseStepParam, playerReducer, shouldAutoplay } from '@/lib/player-state';
import { changedAt, firstFailingStep, scoreAt, stateAt } from '@/lib/replay-state';
import { AgentPanel } from './agent-panel';
import { Scorecard } from './scorecard';
import { Scrubber } from './scrubber';

export interface PlayerProps {
  replay: Replay;
  notes?: Record<number, string>;
  mode?: 'full' | 'compact';
  autoplay?: boolean;
  /** Where the first render starts: the final step (informative HTML) or the beginning. */
  startAt?: 'start' | 'end';
  onEnded?: () => void;
}

export function Player({ replay, notes = {}, mode = 'full', autoplay = false, startAt = 'end', onEnded }: PlayerProps) {
  const total = replay.steps.length;
  const [s, dispatch] = useReducer(playerReducer, initialPlayer(total, startAt === 'end' ? total : 0));

  useEffect(() => {
    const reduced = window.matchMedia?.('(prefers-reduced-motion: reduce)').matches ?? false;
    if (shouldAutoplay(autoplay, reduced)) dispatch({ type: 'play' });
  }, [autoplay, replay]);

  useEffect(() => {
    if (mode !== 'full') return;
    const step = parseStepParam(window.location.search, total);
    if (step !== null) dispatch({ type: 'seek', step });
  }, [mode, total]);

  useEffect(() => {
    if (!s.playing) return;
    const timer = setInterval(() => dispatch({ type: 'tick' }), mode === 'compact' ? 1600 : 1400);
    return () => clearInterval(timer);
  }, [s.playing, mode]);

  useEffect(() => {
    if (!s.ended || !onEnded) return;
    const timer = setTimeout(onEnded, 2500);
    return () => clearTimeout(timer);
  }, [s.ended, onEnded]);

  useEffect(() => {
    if (mode !== 'full') return;
    const onKey = (e: KeyboardEvent) => {
      if ((e.target as HTMLElement | null)?.closest('input, textarea, select, button, [contenteditable]')) return;
      if (e.key === ' ') {
        e.preventDefault();
        dispatch({ type: 'toggle' });
      } else if (e.key === 'ArrowRight') dispatch({ type: 'next' });
      else if (e.key === 'ArrowLeft') dispatch({ type: 'prev' });
    };
    window.addEventListener('keydown', onKey);
    return () => window.removeEventListener('keydown', onKey);
  }, [mode]);

  useEffect(() => {
    if (mode !== 'full') return;
    const url = new URL(window.location.href);
    url.searchParams.set('step', String(s.step));
    window.history.replaceState(null, '', url);
  }, [s.step, mode]);

  const state = useMemo(() => stateAt(replay, s.step), [replay, s.step]);
  const changed = useMemo(() => changedAt(replay, s.step), [replay, s.step]);
  const failAt = useMemo(() => firstFailingStep(replay), [replay]);

  return (
    <section aria-label="Run replay">
      <div className={mode === 'full' ? 'grid gap-4 lg:grid-cols-[1.35fr_1fr]' : 'grid gap-3 md:grid-cols-[1.35fr_1fr]'}>
        <StorePanel state={state} changed={changed} />
        <div className="min-w-0 overflow-hidden rounded-xl border border-border bg-surface">
          <AgentPanel replay={replay} step={s.step} note={notes[s.step]} />
          <Scorecard replay={replay} step={s.step} score={scoreAt(replay, s.step)} />
        </div>
      </div>
      <Scrubber
        replay={replay}
        step={s.step}
        playing={s.playing}
        failAt={failAt}
        compact={mode === 'compact'}
        onSeek={(n) => dispatch({ type: 'seek', step: n })}
        onToggle={() => dispatch({ type: 'toggle' })}
      />
    </section>
  );
}
```

```ts
export interface Field {
  name: string;
  type: 'integer' | 'number' | 'string' | 'text' | 'boolean' | 'enum';
  required: boolean;
  options?: string[];
}

type PropSchema = { type?: string; enum?: unknown[]; maxLength?: number };

/** Form fields for a tool's JSON Schema (as returned by POST /api/episodes). */
export function fieldsFor(schema: Record<string, unknown>): Field[] {
  const props = (schema.properties ?? {}) as Record<string, PropSchema>;
  const required = new Set((schema.required as string[] | undefined) ?? []);
  return Object.entries(props).map(([name, p]) => {
    const type: Field['type'] = p.enum
      ? 'enum'
      : p.type === 'integer' || p.type === 'number' || p.type === 'boolean'
        ? p.type
        : (p.maxLength ?? 0) > 500
          ? 'text'
          : 'string';
    return { name, type, required: required.has(name), ...(p.enum ? { options: p.enum.map(String) } : {}) };
  });
}

/** Tool arguments from form values: empty optional fields are left out; numbers are converted. */
export function argsFrom(fields: Field[], values: Record<string, string | boolean>): Record<string, unknown> {
  const out: Record<string, unknown> = {};
  for (const f of fields) {
    const v = values[f.name];
    if (f.type === 'boolean') {
      if (v === true) out[f.name] = true;
      continue;
    }
    if (v === undefined || v === '' || typeof v === 'boolean') continue;
    out[f.name] = f.type === 'integer' || f.type === 'number' ? Number(v) : v;
  }
  return out;
}

/** A readable message for a failed API call (status 0 = network failure). */
export function describeApiError(status: number, body: unknown): string {
  const message = typeof body === 'object' && body !== null && typeof (body as { error?: unknown }).error === 'string' ? (body as { error: string }).error : null;
  if (status === 0) return 'Could not reach the server. Check that it is running and try again.';
  if (status === 404) return 'This episode has expired or does not exist. Start a new one.';
  if (status === 429) return 'Too many requests for now. Wait a minute and try again.';
  if (status === 503) return 'The environment’s database is unavailable right now. Try again shortly.';
  if (status === 400 && message) return message;
  return 'Something went wrong. Try again.';
}
```

```tsx
  try {
    const res = await fetch(path, { method: 'POST', headers: { 'content-type': 'application/json' }, body: JSON.stringify(body) });
    return { status: res.status, body: await res.json().catch(() => null) };

export function TryConsole({ task, recorded }: { task: string; recorded: Recorded[] }) {
  const [episode, setEpisode] = useState<{ id: string; prompt: string; tools: ToolInfo[] } | null>(null);
  const [tool, setTool] = useState('read_policy');
  const [values, setValues] = useState<Record<string, string | boolean>>({});
  const [log, setLog] = useState<LogEntry[]>([]);
  const [score, setScore] = useState<ScoreResult | null>(null);
  const [error, setError] = useState<string | null>(null);
  const [busy, setBusy] = useState(false);

  const current = episode?.tools.find((t) => t.name === tool);
  const fields = useMemo(() => (current ? fieldsFor(current.input_schema) : []), [current]);

  async function start() {
    setBusy(true);
    setError(null);
    const r = await call('/api/episodes', { task });
    setBusy(false);
    if (r.status !== 201) return setError(describeApiError(r.status, r.body));
    const b = r.body as { episode_id: string; task: { prompt: string }; tools: ToolInfo[] };
    setEpisode({ id: b.episode_id, prompt: b.task.prompt, tools: b.tools });
    setLog([]);
    setScore(null);
    setTool('read_policy');
    setValues({});
  }

  async function run() {
    if (!episode) return;
    setBusy(true);
    setError(null);
    const r = await call(`/api/episodes/${episode.id}/step`, { tool, args: argsFrom(fields, values) });
    setBusy(false);
    if (r.status !== 200) return setError(describeApiError(r.status, r.body));
    const s = r.body as { step: number; ok: boolean; result?: unknown; error?: string; done: boolean; score?: ScoreResult };
```

```js
// Checks the production build: every prerendered page has a title, a description and an og:image; the page counts match.
import { readdirSync, readFileSync, statSync } from 'node:fs';
import { join, relative } from 'node:path';

const root = new URL('../.next/server/app/', import.meta.url).pathname;
const pages = [];
const walk = (dir) => {
  for (const name of readdirSync(dir)) {
    const p = join(dir, name);
    if (statSync(p).isDirectory()) walk(p);
    else if (name.endsWith('.html')) pages.push(p);
  }
};
walk(root);

const problems = [];
for (const file of pages) {
  const html = readFileSync(file, 'utf8');
  const rel = relative(root, file);
  if (rel.startsWith('_') || rel === 'not-found.html' || rel.endsWith('404.html')) continue;
  if (!/<title>[^<]+<\/title>/.test(html)) problems.push(`${rel}: no <title>`);
  if (!/<meta name="description" content="[^"]+"/.test(html)) problems.push(`${rel}: no meta description`);
  if (!/<meta property="og:image"/.test(html)) problems.push(`${rel}: no og:image`);
}
const count = (prefix) => pages.filter((p) => relative(root, p).startsWith(prefix) && relative(root, p) !== `${prefix.slice(0, -1)}.html`).length;
const runs = count('runs/');
const tasks = count('tasks/');
if (runs !== 48) problems.push(`expected 48 run pages, found ${runs}`);
if (tasks !== 8) problems.push(`expected 8 task pages, found ${tasks}`);
console.log(`checked ${pages.length} pages (${runs} runs, ${tasks} tasks)`);
if (problems.length) {
  console.error(problems.join('\n'));
  process.exit(1);
}
console.log('all pages have a title, a description and an og:image');
```
